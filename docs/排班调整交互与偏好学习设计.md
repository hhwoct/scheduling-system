# 排班调整交互与偏好学习设计

> 版本：v2.1（2026-08-29，权重 0-1 语义；v2 同日上午为"技能分+加分"版；v1 为 2026-08-26 分支）
> 核心命题：**学习信号的质量 = 调整交互的质量**。店长每次手动调整就是一次「教学」，
> 交互设计决定学习数据是否干净、是否完整。

## 1. 背景与信号模型

偏好学习把「店长手动调整后发布」视为认可样本（详见 docs/交接文档.md §20260825 迁移内容）。
由此得出交互设计的硬要求：

| 学习信号 | 来源动作 | 交互要求 |
|---|---|---|
| 班次偏好 | 换班次 / 换人 | 防误触、可撤销 |
| 工作站偏好 | 移动工作段 / 换工作站 | 防误触、可撤销 |
| 休息偏好 | 切换休息 | 防误触、可撤销 |
| 需求型调整 | 缺人补位（应反馈到人数需求而非学习） | **分类标注**，与偏好型调整分流 |
| 认可信号 | 发布 | 发布前摘要，让店长知道系统将学习什么 |

## 2. 现有交互的问题（基线审查）

1. 调整**一步落库**，误操作无撤销 → 错误信号 + 纠正信号双重污染偏好表；
2. 所有调整混为一谈 → 无法区分「缺人补位（该改需求配置）」与「偏好（该学习）」；
3. 发布无摘要 → 学习黑盒，店长不知道系统在学什么。

## 3. 交互设计（分级实施）

### P0：防噪声（学习质量底线）——本迭代
- **撤销**：每次调整成功后进入可撤销状态（底部撤销条，5 秒窗口，支持连续撤销栈），
  撤销调用反向 API（move-segment 反向移动 / day-status 恢复 / slot-status 恢复）。
- **发布前调整摘要**：发布确认框展示「本期调整 N 处（改休 X / 换班 Y）」，
  并提示「发布后系统将学习这些调整」。

### P1：信号分级（学习质量跃升）
- 调整自动打标：换人 / 改班次 / 移时段 / 改休息；
- 店长可选填原因：「缺人补位」→ 系统提示「是否同步更新人数需求？」；
  「个人安排」→ 进入偏好学习。把「该学什么」和「该改配置」自动分流。

### P2：学习可视化与提效
- 调整色块偏好匹配角标（绿勾 = 与历史一致，灰点 = 新尝试）；
- 框选批量换人/改休；「复制上周」复用店长认可版本再微调。

## 4. 数据流

```
店长调整（ScheduleView）
  → 撤销栈（前端内存，可回退）
  → 落库（现有 move-segment / day-status / slot-status）
  → 发布（ScheduleGenerateView）
      → 调整摘要接口（对比 generated_summary_snapshot）
      → 确认框展示摘要
      → 发布成功 → 偏好学习自动重建（PreferenceService.RebuildAsync）
      → 仪表盘趋势新增一期（贴合率 + 调整数）
```

## 5. 验收口径

- 误操作可撤销（拖动/切休/换站后 5 秒内可回退，无残留脏数据）；
- 发布确认框出现调整摘要，数字与「生成快照 vs 当前」差异一致；
- 发布后 rebuild，趋势表新增一期且 adjustments = 摘要数字。

## 6. 学习应用与连续权重（v2）

### 6.1 开关与语义

- 规则键 preference_learning_weight，**取值范围 0~1**（默认 0 = 关闭，主项目行为不变）；
- **连续权重（线性混合）**：排序分 = 技能分 × (1 − w) + 偏好归一化分 × w，
  其中偏好归一化分 = 认可频次（封顶 10）/ 10 × 技能分标尺（单站 5 分；
  班次分配按覆盖岗位数 × 5）。两个端点语义清晰：
  - w = 0 → 纯技能分排序，与未启用完全一致；
  - w = 1 → 完全按店长偏好（技能分完全不参与）；
  - 0 < w < 1 → 按比例混合，w 越大偏好越主导（如 w = 0.3 时，
    技能差 ≤ 约 2 分的两人之间偏好可翻盘）。
- 硬约束（技能门槛 > 0、工时上限、重叠、单时段人数上限等）始终不受偏好影响，
  偏好只决定「技能分接近时优先谁」。

### 6.2 应用点（PreferenceScoring.EffectiveScore）

| 阶段 | 位置 | 排序键（skillMax） |
|---|---|---|
| 班次分配 | ShiftAllocator 模板班次候选 | TotalSkillScore×(1−w) + ForShift 归一化×w（覆盖岗数×5） |
| 工作站分配 | WorkstationAllocator 2A / 2A+ 参考分配 | SkillScore×(1−w) + ForWorkstation 归一化×w（5） |
| 残差兜底 | ResidualGapFiller.FillBlock 候选 | StationSkillScore×(1−w) + ForWorkstation 归一化×w（5） |
| 休息分配 | RestDayAllocator | ForRest 保持**次级键**（休息无技能分竞争，加权无意义） |

### 6.3 学习信号（已在 v1 后补齐）

- 认可样本：PUBLISHED 计划 summaries（班次/休息）+ results（工作站）；
- 纠错信号：schedule_adjustments（MOVE_SEGMENT / SET_REST / ADJUST 目标方向 +2；
  SET_WORK 属需求信号不学习）；
- 仪表盘：贴合率（最新一期 vs 历史偏好组合）、覆盖率（全职 freq≥3 比例）、
  调整数（发布快照 vs 最终 summaries 差异），趋势表逐期展示。

# 排班系统 功能清单

> 更新日期：2026-08-13

---

## 一、登录与认证

| # | 功能 | 说明 |
|---|------|------|
| 1.1 | 账号密码登录 | 支持 admin / 店长 / 员工 / 兼职多角色登录 |
| 1.2 | JWT 短期令牌 | Token 有效期 30 分钟，过期自动清除并跳转登录 |
| 1.3 | 登录限流 | 每分钟最多 5 次登录尝试 |
| 1.4 | 密码重置 OTP | 忘记密码需用户名+手机号+短信验证码，限流 15 分钟 3 次 |
| 1.5 | 失败锁定 | 连续失败 5 次锁定 15 分钟 |
| 1.6 | 防用户枚举 | 统一错误消息 + 虚拟 bcrypt 验证，不泄露账号是否存在 |
| 1.7 | 路由守卫 | 前端按角色白名单校验，非法角色踢回登录 |

---

## 二、角色与权限

| 角色 | 权限说明 |
|------|---------|
| **SYSTEM_ADMIN（admin）** | 全部功能 + 修改排班规则 |
| **STORE_MANAGER（店长 E001）** | 管理端功能，排班规则**只读** |
| **EMPLOYEE（员工）** | 员工端：查班表/请假/换班/提前返岗 |
| **兼职（E101~E110）** | 员工端 + 排班仅限低技能岗位 |

---

## 三、排班管理（管理端）

| # | 功能 | 说明 |
|---|------|------|
| 3.1 | 一键生成排班 | 自动完成：休息日 → 班次 → 工作站 三段分配 |
| 3.2 | 排班周期选择 | 未来一周 / 本月 / 下月 |
| 3.3 | 草稿自动覆盖 | 同周期已有 DRAFT 时自动删除重生成（已发布需手动删） |
| 3.4 | 并发峰值需求 | 按 (工作站, 时段) 峰值排班，需求满足后多余员工不排班 |
| 3.5 | 兼职自动分配 | 低技能岗位缺口优先用兼职补齐 |
| 3.6 | 周视图 | 甘特图展示员工一周班表 + 低技能岗位兼职替补色块 |
| 3.7 | 月视图 | 日历形式展示每日上班/休息/班次 + 日矩阵明细 |
| 3.8 | 日明细 | 工作站 × 时段矩阵，显示排班员工与缺口标记 |
| 3.9 | 手动调整 | 调整班次/工作站，校验技能匹配 |
| 3.10 | 发布排班 | 已发布后生成员工通知；存在 ERROR 时二次确认强制发布 |
| 3.11 | 删除排班 | 级联删除明细/汇总/问题/换班记录 |

## 四、排班合理性分析

| # | 功能 | 说明 |
|---|------|------|
| 4.1 | 合理度趋势 | `/rationality` 基于实际覆盖÷需求计算每日合理度曲线 |
| 4.2 | 问题汇总卡片 | 问题总数 / 岗位缺口 / 警告级别 / 影响天数 |
| 4.3 | 类型分布环形图 | 岗位缺口/技能不匹配/工时超限/连续工作超限 |
| 4.4 | 缺口分布环形图 | 按工作站展示缺口占比（前8+其他） |
| 4.5 | 问题明细表 | 日期/时段/工作站/类型/严重度/说明，支持点击图筛选 |
| 4.6 | 低技能缺口标记 | 环保洁/咨客/传送/服务缺口显示「兼」，建议兼职填补 |

## 五、规则配置

| # | 功能 | 说明 |
|---|------|------|
| 5.1 | 每月休息天数 | 默认 4 天（按周期比例折算） |
| 5.2 | 最大周工时 | 默认 48 小时 |
| 5.3 | 最大连续工作天数 | 可配置（当前 8 天），**真正约束排班**，达上限强制休息 |
| 5.4 | 夜班后最小休息 | 默认 10 小时 |
| 5.5 | 权限控制 | 仅 SYSTEM_ADMIN 可修改；店长只读 |

## 六、员工管理

| # | 功能 | 说明 |
|---|------|------|
| 6.1 | 员工增删改查 | 工号/姓名/部门/岗位/周工时/状态 |

## 七、员工自助（员工端）

| # | 功能 | 说明 |
|---|------|------|
| 7.1 | 我的班表 | 查看已发布排班（月历视图） |
| 7.2 | 提交请假 | 事假/病假/年假/其他，校验冲突 |

| 7.5 | 我的换班记录 | 查看审批状态 |
| 7.6 | 站内通知 | 排班发布/请假审批/换班审批提醒 |

## 八、审核管理（管理端）

|---|------|------|

| 8.2 | 换班审批 | 通过则自动互换排班明细（事务内） |

## 九、数据与安全

| # | 功能 | 说明 |
|---|------|------|
| 9.1 | 数据看板 | 员工总数（含全职/兼职分解）、班次数、工作站数、门店信息 |
| 9.2 | 密码强度 | 新密码 ≥8位，含大写/小写/数字 |
| 9.3 | 密码哈希 | bcrypt work factor 12 |
| 9.4 | 多租户隔离 | 所有查询按 StoreId 过滤 |
| 9.5 | 并发唯一约束 | 员工号/工作站编码/员工技能/用户名 唯一索引 |
| 9.6 | 审计事务原子化 | 审计日志与业务同事务提交 |

## 十一、技术栈

- **后端**：.NET 10.0 Web API + EF Core + MySQL 8.0
- **前端**：Vue 3 + Element Plus + Vite 6
- **认证**：JWT Bearer + 角色授权策略（AdminOnly / SystemAdminOnly）
- **测试**：xUnit（当前 11 个用例全部通过）

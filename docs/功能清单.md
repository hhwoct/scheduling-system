# 排班系统 功能清单

> 更新日期：2026-08-19

---

## 一、登录与认证

| # | 功能 | 说明 |
|---|------|------|
| 1.1 | 账号密码登录 | 支持 admin / 店长 / 员工 / 兼职多角色登录 |
| 1.2 | JWT 短期令牌 | Token 有效期 24 小时；前端 15 分钟无操作自动清除并跳转登录 |
| 1.3 | 登录限流 | 每分钟最多 5 次登录尝试 |
| 1.4 | 密码重置 OTP | 忘记密码需用户名+手机号+验证码（联调期验证码打印在后端日志 `[DEV-OTP]`，短信网关未接入），限流 15 分钟 3 次 |
| 1.5 | 失败锁定 | 连续失败 5 次锁定 15 分钟 |
| 1.6 | 防用户枚举 | 统一错误消息 + 虚拟 bcrypt 验证，不泄露账号是否存在 |
| 1.7 | 路由守卫 | 前端按角色白名单校验，非法角色踢回登录 |

---

## 二、角色与权限

| 角色 | 权限说明 |
|------|---------|
| **SYSTEM_ADMIN（admin）** | 全部功能 + 修改排班规则 |
| **STORE_MANAGER（店长 E001）** | 管理端功能，排班规则**只读** |
| **EMPLOYEE（员工）** | 员工端：查班表/请假/换班/提前返岗 |
| **兼职（E101~E110）** | 员工端 + 排班仅限低技能岗位 |

## 三、基础数据管理（管理端）

| # | 功能 | 说明 |
|---|------|------|
| 3.1 | 高峰时段 | 配置班中休息禁休时段（30 分钟对齐，默认 20:00-22:00），休息不与高峰重叠 |
| 3.2 | 人数需求 | 平日/周末/节假日 × 工作站 × 半小时时段（营业日 12:00 至次日 06:00，06:00-11:30 闭店）的在岗人数需求，甘特图式编辑；支持「最少/最好」两档（单数字 N = 最少且最好 N；(M,N) = 最少 M 最好 N）、拖动框选批量修改、格子备注（橙点角标，悬停查看） |
| 3.3 | 人数需求-Excel 导入 | 上传 xlsx/xls/csv 自动解析并入配置，支持模板矩阵与「日期类型/工作站/时段/需求人数」长表两种格式，人数列支持 2,3 两档写法 |
| 3.4 | 人数需求-模板导出 | 一键下载当前工作站结构的 Excel 模板（含使用说明表） |
| 3.5 | 人数需求-类型复制 | 支持将某个日期类型的配置复制到另一类型（如周末→节假日） |
| 3.6 | 人数需求-统计 | 每档实时统计最少/最好总需求（人·时）、峰值并发人数及出现时段，并给出三档合计 |
| 3.7 | 周期需求预览 | 生成排班页按所选周期展示各日期类型的天数/需求人·时/峰值并发（营业日口径） |
| 3.8 | AI 识别导入（DeepSeek） | 接入 DeepSeek API 智能解析 Excel/图片中的人数需求（后端代理调用，支持 JSON 结构化输出与逐条校验），识别结果并入编辑器后保存生效 |
| 3.9 | AI 设置 | 在页面配置 DeepSeek API Key / 接口地址 / 模型，支持连通性测试；Key 明文存库但接口仅返回掩码 |
| 3.10 | 技能等级总览 | 全职员工 × 工作站技能矩阵（0-5 分色块 + ★ 主技能标记），支持部门筛选/关键字搜索/只看有技能；点击色块直接修改（管理员与店长均可，主技能唯一）；「通岗」开关 = 自动为楼面低技能岗位（传送/保洁/咨客/服务）写入 ≥3 分、取消时清 0；兼职员工不参与评级（技能保留供算法替补使用） |

## 四、排班管理（管理端）

| # | 功能 | 说明 |
|---|------|------|
| 4.1 | 一键生成排班 | 自动完成四阶段：休息日 → 班次 → 工作站 → 班中休息 |
| 4.2 | 排班周期选择 | 未来一周 / 本月 / 下月 |
| 4.3 | 草稿自动覆盖 | 同周期已有 DRAFT 时自动删除重生成（已发布需手动删） |
| 4.4 | 并发峰值需求 | 按 (工作站, 时段) 峰值排班，需求满足后多余员工不排班 |
| 4.5 | 兼职自动分配 | 低技能岗位缺口优先用兼职补齐 |
| 4.6 | 周视图 | 甘特图展示员工一周班表 + 低技能岗位兼职替补色块 |
| 4.7 | 月视图 | 日历形式展示每日上班/休息/班次 + 日矩阵明细 |
| 4.8 | 日明细 | 工作站 × 时段矩阵，显示排班员工与缺口标记 |
| 4.9 | 手动调整 | 调整班次/工作站，校验技能匹配；日明细里按住色块**拖动**可移动工作段（换工作站/平移时间），拖动时**吸附到 30 分钟格子**并高亮落点，松手落库 |
| 4.10 | 发布排班 | 已发布后生成员工通知；存在 ERROR 时二次确认强制发布 |
| 4.11 | 删除排班 | 级联删除明细/汇总/问题/换班记录 |
| 4.12 | 按需自动补班次 | 模板班次无法覆盖的需求缺口，按连续缺口块自动生成临时班次（D1/D2…，起止时间跟随需求，可跨午夜）并安排员工 |
| 4.13 | 需求覆盖统计 | 生成结果返回周期最少/最好需求人·时、已覆盖人·时、缺口人·时与覆盖率（按最少人数口径） |
| 4.14 | 班中休息分配 | 每次固定 30 分钟；<4 小时班不休息、上班 2h/下班 1h 内禁休、避开高峰禁休时段；冗余不足时借调顶岗（每人每天 ≤2 次），无人顶岗输出 BREAK_UNCOVERED 告警 |

## 十、数据与安全

| # | 功能 | 说明 |
|---|------|------|
| 10.1 | 数据看板 | 员工总数（含全职/兼职分解）、班次数、工作站数、门店信息 |
| 10.2 | 密码强度 | 新密码 ≥8位，含大写/小写/数字 |
| 10.3 | 密码哈希 | bcrypt work factor 12 |
| 10.4 | 多租户隔离 | 所有查询按 StoreId 过滤 |
| 10.5 | 并发唯一约束 | 员工号/工作站编码/员工技能/用户名 唯一索引 |
| 10.6 | 审计事务原子化 | 审计日志与业务同事务提交 |
| 10.7 | password_version 令牌失效 | JWT 携带密码版本，改密码后旧令牌全部失效 |
| 10.8 | 登录限流双维度 | 账号 + IP 双维度计数，成功登录同时清除该 IP 与账号的失败计数/锁定 |
| 10.9 | OTP 不进响应体 | 验证码仅打印在后端日志（非生产 `[DEV-OTP]`），生产不落日志不进响应 |
| 10.10 | 手机号脱敏与校验 | 列表/详情脱敏（前3后4）；新增/编辑校验 11 位 1 开头（保障忘记密码精确匹配） |

## 十二、技术栈

- **后端**：.NET 10.0 Web API + EF Core + MySQL 8.0
- **前端**：Vue 3 + Element Plus + Vite 6
- **认证**：JWT Bearer + 角色授权策略（AdminOnly / SystemAdminOnly）
- **测试**：xUnit（当前 **186 个用例全部通过**；测试数据层 EF Core InMemory + SQLite）
